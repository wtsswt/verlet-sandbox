# Verlet 沙盒

纯前端粒子沙盒：每帧都在解一个约束满足问题——粒子不重叠、连杆长度不变、不跑出地面。

在线：<https://wtsswt.github.io/verlet-sandbox/>

## 每帧三件事

1. **积分** —— 粒子按当前速度前移一步
2. **约束迭代** —— 把违反约束的位置改回来，重复 4 次
3. **渲染**

积分只负责"大致正确"，**约束迭代才决定手感**。

## 为什么用 Verlet

$$x_{n+1} = 2x_n - x_{n-1} + a\,\Delta t^2$$

不存速度，用前后两帧的位置差隐含表示速度：

- 速度是隐式的，改位置即改速度，不必单独维护
- 施加约束时只移动位置；若用速度积分，一次位置修正后速度就不匹配，粒子会抖

力学上这是**位置级约束投影**：约束反力不显式解出，靠反复移动位置逼近满足状态。

## 四种模式

| 模式 | 物理内容 |
| --- | --- |
| 互斥粒子 | 最小间距约束 + 切向摩擦，铺成一床颗粒 |
| 布料 | 网格 + 距离约束，只钉住上边三个点 |
| 软体 | 闭合轮廓 + 距离约束 + 面积约束 |
| 星系 | 中心引力 + 圆轨道初速，轨迹渐隐后再现旋臂 |

## 五种鼠标工具

推开 / 吸引 / 涡旋 / 拖拽 / 连线。

- **推开·吸引·涡旋**：直接改位置而非施加力。力场必须在约束迭代**之前**施加，放在之后会被约束改回去
- **拖拽**：限速跟随（每子步最多 7 px）。直接赋值等于瞬移，连杆一步就被拉爆，抓住的粒子当场脱网
- **连线**：在两颗粒子间拖一条即得一根距离约束。连成网格就是布，连成闭环加面积项就是软体

快捷键：`空格` 暂停 · `R` 重置 · `1`–`4` 切模式 · `?m=cloth` 之类的 URL 参数可直接进某个模式。

## 性能

碰撞用空间网格：画布切成边长 2r 的格子，每颗只和本格及 8 个邻格比较，复杂度从 O(n²) 降到接近 O(n)。一千多颗粒子可稳定 60 fps。

物理步长固定 1/120 s，每帧跑两次，**不用真实帧间隔当 dt**——否则设备一卡就穿模飞屏。

## 踩过的坑

- **布料两个方向都加对角约束 → 整张布变硬板**。每个格子三角化后成了刚体。只用横向 + 纵向的结构约束才是布。
- **软体的面积约束不能朝质心推**。压扁时各点到质心的方向几乎都是水平的，越推越扁；要沿边的外法线推。
- **直接给拖拽点赋指针坐标 → 连杆瞬间超过撕裂阈值**，必须限速跟随。
- **无摩擦圆盘撑不起坡度**。位置修正不消耗能量，颗粒间又无静摩擦，堆多高都会松弛成全宽的一层。加切向速度摩擦并把床做厚。
- **初始排列留 5% 间隙**。按接触距离紧挨着生成，开局就在互相重叠，会被瞬间挤散。
