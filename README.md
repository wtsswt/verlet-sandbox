# Verlet 沙盒

一个纯前端的粒子沙盒。每帧都在解一个约束满足问题：粒子互相不重叠、连杆长度不变、不许跑出地面。

在线地址：**https://wtsswt.github.io/verlet-sandbox/**

没有依赖、没有构建步骤，整个项目就是 `index.html` 一个文件（HTML + CSS + JS 全在里面）。

## 每帧做三件事

1. **积分** —— 让粒子按当前速度往前移动一步
2. **约束迭代** —— 把违反约束的位置改回来，重复 4 次
3. **渲染** —— 画出来

积分只负责"大致正确"，**约束迭代才决定手感**。

## 为什么用 Verlet 而不是 F = ma 积分

$$x_{n+1} = 2x_n - x_{n-1} + a\,\Delta t^2$$

不存储速度，用前后两帧的位置差隐含表示速度：

- **速度是隐式的**：改位置，速度就自动跟着变，不用单独维护速度变量
- **施加约束时只移动位置**：用速度积分的话，一次位置修正之后速度就不匹配了，粒子会抖

从力学上说这是**位置级约束投影**：约束反力没有显式解出来，靠反复移动位置逼近满足状态。跟有限元里迭代求约束是同一类思路，只是迭代对象换成了位置。

## 四种模式

| 模式 | 物理内容 |
|---|---|
| 互斥粒子 | 最小间距约束 + 切向摩擦，铺成一床颗粒 |
| 布料 | 网格 + 距离约束，只钉住上边三个点，拽一角整张布都跟着动 |
| 软体 | 闭合轮廓 + 距离约束 + 面积约束，捏下去会弹回来 |
| 星系 | 中心引力 + 圆轨道初速，轨迹渐隐后再现旋臂 |

## 五种鼠标工具

推开 / 吸引 / 涡旋 / 拖拽 / 连线。

- **推开·吸引·涡旋**：直接改位置，不是施加力。力场必须在约束迭代**之前**施加，放在之后会被约束改回去。
- **拖拽**：限速跟随（每子步最多 7 px）。直接赋值等于瞬移，连杆一步就被拉爆，抓住的那颗会当场脱网飞走。
- **连线**：在两颗粒子之间拖一条，就得到一根杆（距离约束）。连成网格就是布，连成闭环加面积项就是软体。

快捷键：`空格` 暂停 · `R` 重置 · `1`–`4` 切模式 · `?m=cloth` 之类的 URL 参数可直接进某个模式。

## 性能

碰撞用空间网格：画布切成边长 2r 的格子，每颗粒子只和本格及 8 个邻格比较，复杂度从 O(n²) 降到接近 O(n)。一千多颗粒子在普通笔记本上稳定 60 fps。

物理步长固定为 1/120 s，每帧跑两次，**不用真实帧间隔当 dt**。用真实帧间隔的话，设备一卡，粒子就会直接穿模飞出屏幕。

## 踩过的坑

记录下来，免得下次再踩：

- **布料两个方向都加对角约束 → 整张布变成硬板**。每个格子都被三角化后成了刚体，挂在钉子上纹丝不动。只用横向+纵向的结构约束才是布。
- **软体的面积约束不能朝质心推**。压扁的时候所有点到质心的方向几乎都是水平的，朝质心推只会把它越拉越扁。要沿边的外法线推。
- **直接给拖拽点赋指针坐标 → 连杆瞬间超过撕裂阈值**，被抓的那颗当场脱网。必须限速跟随。
- **无摩擦圆盘撑不起坡度**。位置修正不消耗能量，颗粒之间又没有静摩擦，堆多高都会松弛成全宽的一层。加切向速度摩擦，再把床做厚。
- **初始排列留 5% 间隙**。按接触距离紧挨着生成，一开局就在互相重叠，会被瞬间挤散。
